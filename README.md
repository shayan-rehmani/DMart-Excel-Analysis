# DMart Product Pricing & Discount Analysis



## Project Overview

An Advanced Excel portfolio project focused on retail product listings, pricing patterns, and discount analysis. The project uses Excel 365 and Power Query to clean and transform product data, then uses PivotTables and charts to summarize pricing and discount patterns.



## Tools & Technologies

\- Microsoft Excel 365

\- Power Query (ETL and data cleaning)

\- Excel formulas and calculated columns

\- PivotTables and PivotCharts

\- Excel dashboard design

\- Git and GitHub



## Project Workflow

1\. Inspected and cleaned product listing data in Power Query.

2\. Standardized text fields and reviewed missing values.

3\. Created calculated columns for discount amount and discount percentage.

4\. Built PivotTables to analyze categories, brands, and subcategories.

5\. Created KPI cards and a dashboard with bar charts and a donut chart.



## Dashboard KPIs

\- Product records

\- Average listed price

\- Average discounted price

\- Average discount percentage



## Key Analyses

\- Category-level average discount comparisons

\- Brand-level average discount comparisons

\- Subcategory-level average discount comparisons

\- Product catalog distribution by category



## Data Notes

This dataset contains product listing and pricing information. It does not establish actual sales, transaction volume, costs, or profit. Therefore, the project does not claim sales or profitability insights.



Some records with missing brand values were retained or handled according to the context of the product. One zero-price record was excluded from the planned price and discount analysis. Data-treatment decisions should be interpreted in the context of the source dataset.
